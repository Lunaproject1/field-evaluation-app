## Âmbito, dados e riscos residuais

A marcação é atual, manual e por militar; não é uma declaração clínica nem uma exclusão por data. São guardados apenas active/exercises/updatedAt/revision no campo opcional trainingRestriction das avaliações existentes. A alteração não apaga registos nem migra schema de storage/folha. Pontuações, classificações, exercícios excluídos, notas e datas permanecem iguais quando a checkbox muda. CSV/texto/imagem acrescentam a indicação atual; JSON/backup preservam os metadados. O código de exportação de imagem foi atualizado por inspeção, sem gerar preview/imagem no chat.

Os IDs explícitos distinguem homónimos. Para IDs auto-gerados históricos com prefixo soldier_, callsign e DOB existentes mantêm continuidade após promoções/unidade; se estes próprios dados estiverem errados, a identidade exige revisão humana. Não se fez associação ou deduplicação real. Cross-module matching ambíguo omite o marcador e não atribui limitações por suposição.

A antiga build v38.59 preserva campos desconhecidos ao carregar mas não tem editor desta função; usar v38.60 nos dispositivos que vão editar limitações. O backend conserva versões de sync. Conflitos de edições entre dispositivos continuam a exigir revisão explícita.
